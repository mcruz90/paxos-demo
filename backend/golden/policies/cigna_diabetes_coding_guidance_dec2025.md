## Purpose

ICD-10-CM coding education for Cigna Individual & Family Plan (IFP) providers submitting claims for patients with diabetes mellitus. This is a coding guidance document — it is not a PA coverage policy and does not specify PA approval criteria.

## T2DM Remission Definition

Remission is defined as a return of HbA1c to less than 6.5% that occurs spontaneously or following intervention and that persists for at least three months in the absence of usual glucose-lowering pharmacotherapy. Assign E11.A for T2DM without complications in remission.

## Relevant Secondary Codes for GLP-1 Claims

<!-- cite: ICD-10 code table, p. 3 -->

| Code | Description |
|---|---|
| Z79.4 | Long-term (current) use of insulin |
| Z79.84 | Long-term use of oral hypoglycemic drugs / oral antidiabetic drugs |
| **Z79.85** | **Long-term use of injectable non-insulin antidiabetic drugs (e.g., Ozempic®, Trulicity®, Victoza®, etc.)** |

## General Coding Guidance

<!-- cite: General guidance, p. 1 -->

- Assign as many ICD-10 codes from E08–E13 as needed to identify ALL associated conditions.
- Nonspecific codes may be rejected.
- Use combination codes to report diabetes mellitus with a complication (e.g., diabetic CKD requires E11.2- plus N18.x stage code).
- Illustrate cause-and-effect relationships with conclusive linking words ("due to", "caused by", "resulting in"). Avoid "probably", "suspected", "likely".
- If a patient has uncontrolled or abnormal blood sugar, diabetes mellitus must be stated as either hyperglycemia or hypoglycemia for accurate code correlation.

## Notes

- Document scope: IFP plans only. Employer/group plan coding may differ.
- Z79.85 is required as a secondary code alongside the primary diagnosis (e.g., E11.9) when a GLP-1 injectable is the long-term medication.
- This document does not specify PA clinical criteria for GLP-1 agents; see `ozempic_cigna` policy for PA requirements.
